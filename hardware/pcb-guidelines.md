# PCB 设计规则（给画板子的 agent / 工程师）

## 布局

1. **天线净空区**：ESP32-S3-WROOM 天线端探出板边，天线下方及周围 ≥15mm 禁铜禁器件禁走线。
2. **音频信号分区**：麦克风(U2/INMP441)与功放(U3/MAX98357)对角布置，拉大距离；喇叭走线与 I2S 走线不平行、间距 ≥3mm。
3. **I2S 走线**：两组 I2S（0/1）各自等长、≤10cm，源端（MCU 侧）预留 22–100Ω 串阻位（可 DNP）。
4. **供电入口**：USB/电池 → F1(PTC) → 5V 主电力路径加宽 ≥0.8mm；U3 VIN 的 470µF 紧贴引脚。
5. **OLED/按键/蜂鸣等外设**用排针或板对板座，方便换件。

## 接地

6. **星型单点**：U2 GND、U3 GND 分别走短线到 U1 GND 附近的汇流点；喇叭回流（OUT-）直接回 U3 的 GND 脚，不借道其他器件地。
7. 顶层保留完整地平面，底层走信号；两个 GND 汇流点之间不要走任何电流路径。

## 去耦

8. 每颗 IC 的 VCC 2mm 内放 100nF（C2/C3/C4）；3V3 与 5V 各一颗 bulk（C6/C5）。

## 调试与生产

9. 预留 UART0 排针（烧录+日志）、U1 的 BOOT/EN 按键（量产治具可省）、SWD 不需要。
10. 电池分压 R1/R2/C1 靠 ADC 引脚侧放置；预留 GAIN 电阻位（R-GAIN 0Ω 起贴，按听感调）。
11. 板边留 4×M2 或卡扣位（3D 打印外壳对齐用）。

## 与固件的耦合（改动必须同步！）

- 引脚定义唯一来源：`src/config.h` + `hardware/pinmap.json` + `hardware/netlist.md`，三处一起改。
- GPIO7→U3 SD 静音功能：硬件先留线，固件启用时改 `I2S_SPEAKER_SD_PIN` 为 `GPIO_NUM_7`。
